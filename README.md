# Курьерская МАС

Симулятор доставки по городу 30×30. Восемь курьеров работают с тремя ресторанами. В лабораторной №1 описана архитектура, в №2 сравниваются диспетчеризация и обратный аукцион.

[Отчёт №1](MAS-Lab-1.pdf) · [Отчёт №2](MAS-Lab-2.pdf) · [Результаты всех шести прогонов (CSV)](results.csv)

## Результаты

- **Обычный поток.** Оба режима доставили в срок 11 из 12 заказов. Выплаты при диспетчеризации — 870, при аукционе — 395 условных единиц.
- **Тяжёлые заказы.** Оба режима доставили в срок 10 из 12 заказов. Выплаты при диспетчеризации — 970, при аукционе — 467 условных единиц.
- **Пиковый спрос.** Оба режима доставили в срок 9 из 18 заказов. Выплаты при диспетчеризации — 680, при аукционе — 385 условных единиц.

В CSV также указаны время доставки, ожидание выдачи, число сообщений и пробег по заказам и без заказа.

## Запуск

Нужен Python 3.10+ с Tkinter. Из корня репозитория:

```sh
python3 app.py
```

Для демонстрации выберите «Пиковый спрос» и «Обратный аукцион», затем нажмите «Шаг» дважды. В журнале появятся параллельные раунды и назначения. Клик по курьеру показывает маршрут и последнее решение.

Повторить эксперименты и вывести контрольную трассу:

```sh
python3 experiments.py
python3 app.py --trace --scenario control --mode dispatch
```

Первая команда обновляет `results.csv`. В контрольной трассе доставки происходят на тактах 9, 11 и 13.
